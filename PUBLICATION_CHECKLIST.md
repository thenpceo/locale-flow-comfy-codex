# Public GitHub checklist

Before pushing:

- [ ] Confirm permission to publish every source image, athlete likeness, logo, campaign plate, and derivative.
- [ ] Replace restricted source media with cleared demo assets or keep it excluded.
- [ ] Confirm generated-media provider terms permit the intended public use.
- [ ] Keep Six Caps' SIL OFL file beside the font if the font is distributed.
- [ ] Remove Comfy output URLs, signed URLs, local account data, prompt histories, and credentials.
- [ ] Verify saved `LoadImage` filenames are documented as workspace-specific asset references.
- [ ] Remove `.vercel`, local logs, browser captures with private information, and generated run folders.
- [ ] Confirm all fictional routes/addresses are labeled and no factual metadata was invented.
- [ ] Keep “not authorized by Nike or Adobe” visible in the README and presentation.
- [ ] Choose a software license for original code separately from third-party media rights.
- [ ] Run `npm run proof` and inspect desktop/mobile presentation captures.
- [ ] Test the README quick start in a clean clone with cleared replacement assets.

Do not treat a public GitHub repository as a rights-cleared campaign release.
